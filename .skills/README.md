# Скиллы SharedSpace

Перед изменением открой [AGENTS.md](../AGENTS.md) и все подходящие инструкции. Общие правила по комментариям, проверкам и корневому README описаны в AGENTS.md. Для фичи с новым экраном и эндпоинтом понадобятся оба скилла разработки. Если поменялся контракт API, открой также скилл документации.

- [frontend-design](frontend-design/SKILL.md) — новые экраны, компоненты, темы, адаптация и проверка интерфейса.
- [backend-development](backend-development/SKILL.md) — Go, контракты API, права доступа, PostgreSQL, MinIO, миграции и тесты.
- [documentation](documentation/SKILL.md) — README, инструкции по запуску, описание API и редактирование русскоязычных текстов.
