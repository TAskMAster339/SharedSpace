# Безопасность

## Аутентификация

### JWT

- Алгоритм подписи: **HMAC-SHA256** (HS256)
- Access token: 1 час (настраивается через `JWT_TTL`)
- Refresh token: 30 дней (настраивается через `REFRESH_JWT_TTL`)
- Токены содержат: `sub` (user ID), `type` (access/refresh), `email`, `username`, `jti` (уникальный ID)
- Refresh token хранится в БД в виде SHA-256 хэша (не plaintext)

### Хранение токенов на фронтенде

| Токен | Где хранится | Почему |
|-------|-------------|--------|
| Access token | Память (Zustand) | Теряется при перезагрузке — минимальное окно атаки |
| Refresh token | Cookie (`SameSite=Strict`, `Secure`) | Недоступен JS на других сайтах, передаётся только по HTTPS |

### Password policy

- Минимум 8 символов
- Максимум 72 байта (ограничение bcrypt)
- Обязательно: заглавные + строчные буквы + спецсимвол
- Хэширование: **bcrypt** (через `golang.org/x/crypto`)

### Ротация refresh-токенов

- Каждый вызов `/auth/refresh` отзывает старый refresh token
- Выдаётся новая пара токенов
- Повторное использование старого refresh token невозможно
- При logout токен явно отзывается в БД

## CORS

Политика CORS настраивается через middleware (`internal/middleware/cors.go`):

- Разрешены все origins (настраивается под production)
- Методы: GET, POST, PATCH, DELETE, OPTIONS
- Заголовки: Content-Type, Authorization, X-SharedLink-Password

## Контроль доступа (RBAC)

### Матрица разрешений

| Действие | Владелец | Admin | Editor | Viewer |
|----------|----------|-------|--------|--------|
| Просмотр | ✓ | ✓ | ✓ | ✓ |
| Скачивание | ✓ | ✓ | ✓ | ✓ |
| Загрузка | ✓ | ✓ | ✓ | ✗ |
| Создание папок | ✓ | ✓ | ✓ | ✗ |
| Удаление | ✓ | ✓ | ✗ | ✗ |
| Приглашение | ✓ | ✓ | ✗ | ✗ |
| Смена роли | ✓ | ✓ | ✗ | ✗ |
| Удаление участника | ✓ | ✓ | ✗ | ✗ |
| Удаление директории | ✓ | ✓ | ✗ | ✗ |
| Публичная ссылка | ✓ | ✓ | ✗ | ✗ |

Владелец директории всегда имеет полный доступ. Роли проверяются через рекурсивный CTE в PostgreSQL для поиска владельца директории.

## Пароли на публичных ссылках

- Пароль для публичной ссылки хранится в виде **bcrypt-хэша**
- Передаётся через заголовок `X-SharedLink-Password`
- Кодируется через `encodeURIComponent` на клиенте

## PostgreSQL

- Пул соединений: min 2, max 10
- Healthcheck: `pg_isready`
- Используются prepared statements через `pgx/v5`
- Миграции применяются автоматически при старте

## MinIO

- Два bucket: основной и временный (для конвертации)
- Временный bucket: префикс `conv/`, автоочистка каждые 15 минут (файлы старше 30 минут)
- Presigned URL: 24 часа действительны
- Доступ к временным файлам конвертации удаляется после очистки

## Docker

- Минимизация образов: `golang:1.26-alpine` для сборки, `alpine:latest` для рантайма
- ffmpeg устанавливается только в production-образ
- Бэкенд и фронтенд запускаются от непривилегированных пользователей
