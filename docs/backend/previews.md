# Превью медиафайлов

`GET /api/v1/files/{id}/preview` (Bearer token) возвращает `{ "url": "..." }` — подписанную ссылку MinIO на один час. Проверяется право просмотра директории; для файлов в корзине превью доступно только владельцу файла.

Превью создаётся при первом показе файла, поэтому поддерживаются и ранее загруженные файлы. Изображения и первый кадр видео обрабатываются FFmpeg: JPEG, максимум 256×256 без увеличения исходника, с сохранением пропорций. Результат ограничен 128 КиБ. При ошибке интерфейс оставляет иконку.

Объекты сохраняются в основном бакете под `previews/v1/<uuid>.jpg`. Миграция `010_file_previews.up.sql` создаёт таблицу с ключом объекта, размером и MIME-типом. Это служебный кеш: размер превью не входит в пользовательскую квоту.

Обработка ограничена двумя одновременными запросами и таймаутом 45 секунд. Исходник пишется во временный файл на диске и удаляется после обработки. В Docker файлы хранятся в отдельном каталоге `/app/preview-tmp` в слое контейнера. При запуске бэкенд удаляет оттуда остатки прошлой генерации. Для ручного запуска можно задать `PREVIEW_TMP_DIR` с отдельным каталогом на экземпляр. Если переменная пуста, бэкенд создаёт уникальный временный каталог. Блокировка строки файла предотвращает дублирование генерации и конфликт с окончательным удалением.

При перемещении в корзину превью сохраняется для восстановления. При окончательном удалении файла, дерева папок или аккаунта запись превью удаляется каскадно. Каждые 15 минут worker проверяет объекты MinIO порциями до 500 ключей и удаляет объекты старше часа без записи в БД. Если двухминутный дедлайн истёк, следующий проход продолжает с последнего обработанного ключа. Неудачные удаления повторяются при следующем полном обходе. Такой же механизм очищает объекты после незавершённых транзакций. Превью существующих файлов сохраняются до окончательного удаления исходника.

Перед запуском примените миграцию 010 существующим механизмом проекта. FFmpeg уже установлен в backend Docker-образе. Для локальных тестов обработки медиа он также должен быть доступен в PATH.
