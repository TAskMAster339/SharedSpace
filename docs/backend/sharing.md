# Совместный доступ

## Общие директории

Пользователь может открыть доступ к своей директории другим пользователям. При создании директории можно сразу указать `shared=true`, чтобы сделать её общей.

### Ограничения

- Лимит общих директорий — **5** на пользователя
- Только владелец может создавать общие директории

## Участники и роли

У каждой общей директории есть участники с ролями:

| Роль | Права |
|------|-------|
| `admin` | Полный доступ, управление участниками |
| `editor` | Просмотр, скачивание, загрузка, создание папок |
| `viewer` | Просмотр и скачивание |

Владелец всегда имеет полные права (все действия).

## Приглашения (Invitations)

Процесс добавления пользователя в общую директорию:

1. Владелец/admin создаёт приглашение: `POST /api/v1/shared-directories/{id}/invitations`
2. Приглашаемый пользователь получает уведомление
3. Пользователь может **принять** или **отклонить** приглашение
4. Владелец/admin может **отозвать** приглашение

### Статусы приглашений

| Статус | Описание |
|--------|----------|
| `pending` | Ожидает ответа |
| `accepted` | Принято (участник добавлен) |
| `declined` | Отклонено |
| `revoked` | Отозвано |

## Публичные ссылки (Share Links)

Любой файл или директорию можно сделать публично доступными через ссылку.

### Типы доступа

| Тип | Описание |
|-----|----------|
| `public` | Доступно всем (без аутентификации) |
| `authenticated` | Только аутентифицированным пользователям |

### Дополнительные возможности

- **Срок действия** — ссылка может быть временной
- **Защита паролем** — ссылка может требовать пароль

### Ограничения

- Лимит публичных ссылок — **100** на пользователя

### Open Graph

Для публичных ссылок генерируются Open Graph мета-теги для корректного отображения превью в соцсетях и мессенджерах. Реализовано в sharelinks через `ServeOG` и `ServeDirectoryOG`.
