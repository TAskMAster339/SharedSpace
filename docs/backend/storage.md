# Файловое хранилище

## MinIO

В проекте используется **MinIO** — S3-совместимое объектное хранилище. Каждый файл хранится как объект с уникальным ключом (`object_key`).

### Два bucket'а

| Bucket | Назначение |
|--------|------------|
| Основной (main) | Постоянное хранение пользовательских файлов |
| Временный (tmp) | Эфемерные результаты конвертации (префикс `conv/`) |

### Методы Storage Client

| Метод | Описание |
|-------|----------|
| `Upload` | Загрузка файла в MinIO |
| `PresignedGetURL` | Получение временной ссылки на чтение |
| `PresignedDownloadURL` | Получение временной ссылки на скачивание (с Content-Disposition) |
| `Get` | Прямое чтение объекта |
| `Delete` | Удаление объекта |
| `ListObjects` | Список объектов по префиксу |

### Ограничения

- Максимальный размер загружаемого файла: **100 MB**

## Конвертация файлов

Поддерживается конвертация между форматами с использованием **ffmpeg**.

### Определение формата

Формат определяется по **magic bytes** (сигнатуре файла), а не по расширению:

- PNG, JPEG, GIF, BMP, TIFF, WebP
- AVI, WAV, WebM, MKV, MP3, AAC, FLAC, OGG, MOV, MP4

### Матрица конвертации

Формат определяется по **magic bytes** (сигнатуре файла), а не по расширению. Алгоритмы конвертации:

- Изображения: декодирование через Go image, кодирование через `golang.org/x/image` + `nativewebp`
- Видео/аудио: через ffmpeg (обёртка `u2takey/ffmpeg-go`)

#### Определение формата

```go
// Определение по magic bytes (первые байты файла)
Проверяются сигнатуры:
- PNG: 89 50 4E 47 ...
- JPEG: FF D8 FF
- GIF: 47 49 46 38
- BMP: 42 4D
- TIFF: 49 49 2A 00 / 4D 4D 00 2A
- WebP: 52 49 46 46 ... 57 45 42 50
- MP4 / MOV: ftyp box
- AVI: 52 49 46 46 ... 41 56 49 20
- WAV: 52 49 46 46 ... 57 41 56 45
- MP3: ID3 или ff fb / ff f3 / ff f2
- и т.д.
```

### Жизненный цикл конвертации

1. Пользователь запрашивает конвертацию файла
2. Файл скачивается из MinIO во временную директорию
3. ffmpeg выполняет конвертацию
4. Результат загружается обратно в MinIO
5. Если `save=true` — создаётся запись в `file_conversions`
6. Если `save=false` — возвращается временная ссылка на скачивание (результат во временном bucket)

### Очистка

Фоновый worker запускается каждые **15 минут** и удаляет временные файлы конвертации старше **30 минут** из bucket `conv/`.
