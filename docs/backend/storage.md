# Файловое хранилище

## MinIO

В проекте используется **MinIO** — S3-совместимое объектное хранилище. Каждый файл хранится как объект с уникальным ключом (`object_key`).

### Два bucket'а

| Bucket | Назначение |
|--------|------------|
| Основной (main) | Постоянное хранение пользовательских файлов |
| Временный (tmp) | Эфемерные результаты конвертации (префикс `conv/`) |

### Методы Storage Client

| Метод | Описание |
|-------|----------|
| `Upload` | Загрузка файла в MinIO |
| `PresignedGetURL` | Получение временной ссылки на чтение |
| `PresignedDownloadURL` | Получение временной ссылки на скачивание (с Content-Disposition) |
| `Get` | Прямое чтение объекта |
| `Delete` | Удаление объекта |
| `ListObjects` | Список объектов по префиксу |

### Ограничения

- До **512 МиБ** файлов суммарно за одну загрузку. Nginx и Go ограничивают multipart-запрос **513 МиБ**, включая служебные поля. Превышение размеров возвращает HTTP 413. Квота проверяется перед записью в MinIO и повторно в транзакции.

## Конвертация файлов

Поддерживается конвертация между форматами с использованием **ffmpeg**.

### Определение формата

Формат определяется по **magic bytes** (сигнатуре файла), а не по расширению:

- PNG, JPEG, GIF, BMP, TIFF, WebP
- AVI, WAV, WebM, MKV, MP3, AAC, FLAC, OGG, MOV, MP4

### Матрица конвертации

ffmpeg обрабатывает изображения, видео и аудио в контейнере `media-worker`.

### Очередь и публикация результата

API ставит задачи превью и конвертации в PostgreSQL. Воркер загружает исходник во временный файл, запускает ffmpeg и передаёт результат в MinIO. Он завершает задачу после проверки срока аренды, исходного объекта и прав пользователя. Сохранение файла, записи истории, счётчиков и квоты проходит в одной транзакции с завершением задачи. При сбое между записью в MinIO и коммитом повторная попытка использует другой объект.

Кэшированное превью выдаётся сразу после проверки доступа. Размер исходника и результата конвертации ограничен 512 МиБ. Превью ограничено 128 КиБ. Скачиваемый результат доступен до 30 минут с загрузки в MinIO. Подписанная ссылка действует до 15 минут в пределах срока результата.

### Очистка

Раз в 15 минут очистка удаляет результаты скачивания старше 30 минут из временного бакета под префиксом `conv/`. В основном бакете она проверяет объекты превью и сохранённых конвертаций старше часа. Объект сохраняется, пока на него ссылается превью, файл или версия файла. Завершённые задачи и ключи запросов хранятся в PostgreSQL 24 часа.
