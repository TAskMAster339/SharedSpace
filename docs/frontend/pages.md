# Страницы приложения

## 1. MainPage — `/`

**Назначение:** Публичная лендинг-страница для неавторизованных пользователей.

**Функциональность:**
- Hero-секция с CSS-анимацией (вращающаяся «планета» с иконками-спутниками: Users, Link2, Eye, RefreshCw) на фоне `bg-starfield`
- Секция «Возможности» (5 карточек с описанием функций)
- Секция «Как это работает» (пошаговая инструкция)
- Плавный скролл к секциям по URL-хешу (`#features`, `#how-it-works`)

**Когда показывается:** Только для неавторизованных. После логина редирект на `/dashboard`.

---

## 2. LoginPage — `/login`

**Назначение:** Форма входа.

**Функциональность:**
- Поля: email/username, пароль
- Переключатель видимости пароля
- Валидация на стороне клиента
- Показ ошибок 401 как «Неверный email или пароль»
- Успешный вход → редирект на `/dashboard`

**Использует:** `useAuth().login`, `PublicRoute`

---

## 3. RegisterPage — `/register`

**Назначение:** Форма регистрации.

**Функциональность:**
- Поля: username, имя, фамилия, email, пароль, подтверждение пароля
- Валидация email (регулярное выражение), пароля (мин. 8 символов), совпадения подтверждения
- Обязательное принятие политики конфиденциальности
- После успешной регистрации — автоматический логин (редирект на `/dashboard`)
- Ошибки конфликта (email/username заняты) показываются под соответствующими полями

**Использует:** `useAuth().register`

---

## 4. DashboardPage — `/dashboard`

**Назначение:** Главная страница авторизованного пользователя. Центральный хаб для быстрого доступа к последним файлам, общим директориям и избранному.

**Функциональность:**
- Приветствие с именем пользователя
- Три панели:
  - **Недавние файлы** (до 5, сортировка по `updated_at DESC`)
  - **Общие директории** (до 5)
  - **Избранное** (до 3)
- В каждой панели: список элементов, кнопка «Смотреть всё»
- Для файлов: скачивание, избранное, конвертация, создание ссылки
- Поддержка drag-and-drop загрузки (через `DropZoneWrapper`)

**Использует:** `getRecentFiles`, `getSharedWithMe`, `useFavorites`, `ShareLinkModal`, `ConvertModal`

---

## 5. DirectoryPage — `/directories/:id`

**Назначение:** Основная страница просмотра содержимого директории. Файловый менеджер.

**Функциональность:**
- Два режима просмотра: **сетка** (grid) и **список** (list) — сохраняется в localStorage
- **Хлебные крошки** (breadcrumb): навигация от корня до текущей папки
- **Поддиректории**: создание, переименование, удаление (в корзину), восстановление
- **Файлы**: загрузка (через DropZone или модалку), drag-and-drop перемещение между папками, скачивание, избранное, конвертация, удаление, создание публичных ссылок
- **Бесконечный скролл** для файлов и поддиректорий (по 20 элементов)
- **Контекстное меню** действий через `ItemActionsMenu` (три точки)
- **Модалка перемещения** файла (`MoveFileModal`) с навигацией по дереву папок
- Права доступа: UI адаптируется под роль пользователя (скрывает кнопки загрузки/создания для `viewer`)
- Общие директории: кнопка «Настройки» → `SharedSettingsPage`

**Путь:** `/directories/:id` (параметр `id` — UUID директории)

---

## 6. FileViewPage — `/files/:id`

**Назначение:** Детальный просмотр файла с превью и метаданными.

**Функциональность:**
- **Превью** (определяется по MIME-типу и расширению):
  - Изображения: `<img>` — `previewType = 'image'`
  - Видео: `<video>` с controls
  - Аудио: `<audio>` с плеером
  - PDF: `<iframe>`
  - Текст/код: `<iframe>` с Blob URL (text/html обёртка)
  - Офисные форматы (docx, xlsx, pptx) и архивы: сообщение «Предпросмотр недоступен» + кнопка скачивания
- **Метаданные**: имя, тип, размер, дата создания, дата обновления
- **Информация о владельце**: username владельца
- **Кнопки действий**: скачать, поделиться, избранное, конвертировать, удалить
- **Навигация назад**: кнопка «Назад» ведёт в родительскую директорию с `state.fromFile` для корректной перезагрузки
- **SEO**: `react-helmet-async` с og:image для изображений

---

## 7. FavoritesPage — `/favorites`

**Назначение:** Все файлы, добавленные пользователем в избранное.

**Функциональность:**
- Список избранных файлов с бесконечным скроллом (курсорная пагинация по `favorited_at DESC`)
- Каждый файл: имя, дата, размер, тип
- Действия: убрать из избранного, удалить, скачать, конвертировать, поделиться
- Удаление из избранного → немедленное удаление из списка + Toast с undo
- Удаление файла → Toast с restore

**Использует:** `useFavorites`, `getFavorites` (аякс с пагинацией), `DropZoneWrapper`

---

## 8. TrashPage — `/trash`

**Назначение:** Корзина с удалёнными файлами и директориями.

**Функциональность:**
- Две секции: удалённые директории и удалённые файлы
- Каждый элемент: имя, дата удаления, размер
- **Восстановление**: вызывает `restoreFile` / `restoreDirectory` → элемент исчезает
- **Безвозвратное удаление**: подтверждение через `ConfirmModal` → элемент исчезает
- **Бесконечный скролл** для обеих секций (разные курсоры для файлов и директорий)
- Восстановление директории каскадно восстанавливает все её файлы

---

## 9. SharePage — `/share/:token`

**Назначение:** Публичная страница файла, доступного по ссылке.

**Функциональность:**
- Загрузка данных по токену через `resolveShareLink`
- **Password gate**: если ссылка защищена паролем, показывается форма ввода пароля
- **Превью файла**: те же типы, что и в `FileViewPage` (изображения, видео, аудио, PDF, текст/код)
- **Скачивание**: через presigned URL
- **SEO**: мета-теги через `ServeOG`
- Доступна без аутентификации

---

## 10. SharedDirectoryPage — `/share/dir/:token`

**Назначение:** Публичная страница директории, доступной по ссылке.

**Функциональность:**
- Загрузка содержимого директории по токену через `resolveDirectoryShareLink`
- **Password gate** (опционально)
- Навигация по поддиректориям (обновление `?dir=` параметра в URL)
- Два режима просмотра: сетка/список (localStorage)
- **Превью файлов**: при клике на файл открывается лейаут 2/3 + 1/3 (превью + метаданные)
- **Контекстное меню** (правый клик): скачать, копировать ссылку
- **Хлебные крошки** с навигацией
- **Бесконечный скролл** для файлов и поддиректорий

---

## 11. SharedDirListPage — `/directories`

**Назначение:** Список всех общих директорий пользователя (созданных и тех, куда добавлен).

**Функциональность:**
- Карточки директорий: название, роль пользователя, количество участников, количество файлов, аватарки участников
- Кнопка «Создать общую папку» → модальное окно с вводом названия
- **Индикатор квоты**: использовано/лимит общих директорий
- Каждая карточка — ссылка на соответствующую `DirectoryPage`

**Использует:** `getSharedWithMeStats`, `getMembers`, `createDirectory` (с `shared: true`), `DirectoryCard`

---

## 12. SharedSettingsPage — `/shared/:id/settings`

**Назначение:** Управление участниками общей директории (для владельца и admin).

**Функциональность:**
- Список участников с аватарками, username, ролью, датой присоединения
- **Invite**: поиск пользователя и отправка приглашения (роль по умолчанию — `viewer`)
- **Change role**: выпадающий список ролей (`viewer` / `editor` / `admin`)
- **Remove member**: удаление участника (кроме владельца)
- **Danger Zone**: удаление директории (soft delete) с подтверждением
- Для не-admin: read-only просмотр списка участников

**Использует:** `inviteToDirectory`, `changeMemberRole`, `removeMember`, `softDeleteDirectory`

---

## 13. InvitationsPage — `/invitations`

**Назначение:** Все приглашения в общие директории.

**Функциональность:**
- Список **pending** приглашений: кто пригласил, в какую директорию, с какой ролью
- Кнопки **Принять** / **Отклонить**
- После действия: приглашение исчезает из списка
- Бесконечный скролл

**Использует:** `getMyInvitations`, `acceptInvitation`, `declineInvitation`

---

## 14. ProfileSettingsPage — `/settings`

**Назначение:** Настройки профиля пользователя.

**Функциональность:**
- Шапка профиля: градиентный баннер + аватар с первой буквой username
- **Личные данные**: имя, фамилия, username, email — редактирование с кнопками Сохранить/Отмена
- **Безопасность**: смена пароля (старый → новый → подтверждение), показ/скрытие пароля
- **Опасная зона**: удаление аккаунта с двухшаговым подтверждением через `ConfirmModal`

**Использует:** `useAuth().updateProfile`, `useAuth().changePassword`, `useAuth().deleteAccount`

---

## 15. Error404Page — `*`

**Назначение:** Страница 404.

**Функциональность:**
- Крупный «404» в цветах бренда
- Сообщение «Страница не найдена»
- Кнопка «На главную» → `/dashboard` (или `/` для неавторизованных)
- SEO-теги
